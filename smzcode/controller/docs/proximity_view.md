# 接近觉 2×2 三维柱状图

连接黏附脚，在主界面“粘附脚传感器”下点击“接近觉 2×2 三维图”。独立窗口显示真实接收的四路接近觉，不要求启动控制器或开始保存数据。尚未收到数据时显示 `--`；断开连接清空柱状图；超过 1 秒没有新样本时提示数据超时。

默认布局按用户确认的黏附脚俯视图排列：

| | 左 | 右 |
| --- | --- | --- |
| 上 | JJJ1_1 | JJJ2_1 |
| 下 | JJJ1_2 | JJJ2_2 |

右侧四角下拉框可交换位置，点击“保存位置”写入 `controller/config/proximity_layout.json`，重启后沿用。恢复默认位置后也需点击保存，才会覆盖已保存的布局。三维图可以拖动旋转，四角的物理方位以右侧俯视布局为准。

## 信号含义

柱高使用下位机已清零的相对接近觉信号，保持正负号，不取绝对值、不做各通道独立归一化。数据来自真实 0x123 帧在上位机内部 `raw` 数组的四个位置：

| 通道 | raw 索引（从 0 开始） | 内部历史字段 | 下位机采集来源 |
| --- | --- | --- | --- |
| JJJ1_1 | 5 | JJJ1_1 | 第一片 CIN9 → Stage7 |
| JJJ1_2 | 6 | JJJ1_2 | 第一片 CIN4 → Stage4 |
| JJJ2_1 | 12 | flag1 | 第二片 CIN9 → Stage7 |
| JJJ2_2 | 13 | flag2 | 第二片 CIN4 → Stage4 |

上表对应主版本的 10 Stage 配置。CIN 编号、Stage 编号、raw 索引是三个不同的编号；Stage9 是 CIN11 的受力信号，不能用作第一路接近觉。接近觉测试版使用 5 Stage 配置，其 CIN9 在 Stage3，索引不可直接照搬到主版本。

显示值与 CSV 的四个 `JJJ*_raw` 列一致。这里的 raw 是下位机清零后的信号，并非 AD7142 的绝对电容读数。显示未换算为距离、力或角度。

右侧同时显示右侧两路均值减左侧两路均值、上侧两路均值减下侧两路均值、四路最大值减最小值。差值单位与柱高相同，只用于比较，不自动给出旋转方向或“已对齐”的判断。通道零点、安装高度、灵敏度和目标表面会影响读数，四路等高不直接证明几何对齐。对平面目标，四点距离主要辅助观察平行度；绕表面法向的偏航需结合机械基准判断。

## 显示操作

- “暂停显示”：冻结当前画面及四角位置，采集、保存和控制器继续运行；取消暂停后显示最新数据并恢复位置调整。
- “锁定纵轴范围”：保持当前量程，便于连续比较；信号超出量程时，数值卡仍保留实际值。
- “恢复视角 / 自适应纵轴”：恢复初始视角并按信号重新设置量程。
- 关闭窗口停止绘图定时器；再次点击主界面按钮复用窗口并恢复显示。

窗口使用现有 GUI 的 10 Hz 数据通知缓存最新样本，每 200 ms 绘图一次（5 Hz），不修改真实采样节拍、控制器入口、通信协议或 CSV 保存回调。绘图在 GUI 线程中执行，采集和控制算法沿用原有工作线程。

## 依赖与运行

新增绘图库 Matplotlib；在 `smzcode` 目录下，用运行上位机的同一 Python 环境执行：

```powershell
python -m pip install -r requirements.txt
python apps/main_window.py
```

代码分工：`controller/visualization/proximity_data.py` 提取与校验信号、计算差值及读写位置配置；同目录的 `proximity_view.py` 负责窗口与绘图；主界面仅负责按钮、连接状态和显示数据转发。
